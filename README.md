# Instagram City

A low-poly isometric modern city prototype built with React, Vite, Three.js and React Three Fiber.

## Getting started

```bash
npm install
npm run dev
```

## Current prototype

- Isometric 3D camera with pan and zoom
- Low-poly grass terrain, roads and sidewalks
- Central plaza with a fountain
- Modern low-poly buildings and trees
- Responsive HUD for desktop and mobile

The current scene is a visual landscape prototype. Resident simulation, accounts, persistence and Instagram integration are planned for later milestones.
